# Customer Feedback Sentiment Analysis using NLP

## Overview
This repository contains my final-year thesis on customer feedback sentiment analysis using Natural Language Processing (NLP) and transformer-based deep learning models.

## Objectives
- Analyze customer reviews
- Compare transformer models
- Evaluate model performance

## Technologies
- Python
- TensorFlow
- Scikit-learn
- Pandas
- NumPy
- Google Colab

## Models
- BERT
- DistilBERT
- ELECTRA
- Qwen

## Results
- Processed over 50,000 customer reviews
- Achieved over 56% classification accuracy
- Compared models using Accuracy, Precision, Recall, and F1-score
